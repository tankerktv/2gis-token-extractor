# 2gis-token-extractor

Печатает свежий токен доступа к 2ГИС в стандартный вывод. Больше ничего.

*[English version](README.md)*

```bash
2gis-token login                        # один раз: откроется браузер, входишь сам
export ZOND_TOKEN="$(2gis-token get)"   # дальше — по требованию
```

Токен нужен всему, что разговаривает с сервисом 2ГИС: скриптам, своим
поделкам, чужим программам. Единственный описанный способ его добыть — открыть
DevTools и скопировать руками из адреса веб-сокета. Программа делает это за
тебя.

Она устроена как `aws configure` или `gh auth token`: выдаёт учётные данные,
а что с ними делать дальше — не её забота. Ничего никуда не отправляет, чужих
конфигов не правит и не знает, что ты собираешь.

---

## Чего она не делает

**Не реализует вход в 2ГИС.** Вход — это телефон и код из SMS, а авторизацию
сервисы защищают старательнее всего: там бывает капча, подпись приложения,
проверка устройства. Логинится настоящий браузер, программа только забирает
результат. Ни номер, ни код через неё не проходят.

**Не хранит токен.** Токен уходит в stdout и на этом исчезает. В файл он
попадает, только если попросили ключом `--out`, и никогда не появляется в
логах — вместо него печатается отпечаток.

## Установка

**Через [pipx](https://pipx.pypa.io/)** — основной способ:

```bash
pipx install 2gis-token-extractor
2gis-token install-browser
```

`install-browser` скачивает Chromium для Playwright. Это разовое действие,
примерно 150 МБ.

**Без Python:** возьми однофайловую сборку под свою систему в
[релизах](https://github.com/tankerktv/2gis-token-extractor/releases), положи
куда-нибудь в `PATH` и один раз выполни `2gis-token install-browser`.

## Как пользоваться

### `login` — один раз

```bash
2gis-token login
```

Откроется окно браузера на 2gis.ru. Входишь обычным способом: номер телефона,
код из SMS. Окно закроется само, как только сессия будет готова.

На диск ложится сессия браузера — куки, и больше ничего. См.
[Где лежит сессия](#где-лежит-сессия).

### `get` — каждый раз, когда нужен токен

```bash
2gis-token get
```

Запускает браузер без окна с сохранённой сессией и печатает токен:

```
0123456789abcdef0123456789abcdef01234567
```

Это весь вывод — одна строка без украшений, чтобы её можно было подставить
в конвейер:

```bash
export ZOND_TOKEN="$(2gis-token get)"
curl "https://api.auth.2gis.com/2.1/users/me?access_token=$(2gis-token get)"
```

| Ключ | Что делает |
|---|---|
| `--json` | печатает подробности: токен, откуда пойман, путь к сессии |
| `--out ФАЙЛ` | пишет токен в файл; stdout остаётся пустым |
| `--timeout СЕК` | сколько ждать токен (по умолчанию 60) |
| `--headed` | показать окно браузера — когда что-то идёт не так |

### `check` — жив ли токен

```bash
2gis-token check                  # возьмёт свежий токен из сохранённой сессии
2gis-token check --token ТОКЕН    # проверит тот, что дали
echo "$TOKEN" | 2gis-token check --token -
```

Спрашивает профиль у `api.auth.2gis.com` и различает три исхода — они лечатся
по-разному, и сливать их в один нельзя:

| Исход | Код | Что делать |
|---|---|---|
| токен работает | 0 | ничего |
| токен не принят | 2 | `2gis-token login` |
| 2ГИС ответил своей ошибкой | 1 | подождать, сессия ни при чём |
| нет сети | 4 | проверить связь |

## Коды возврата

Рассчитаны на скрипты:

| Код | Значение |
|---|---|
| 0 | успех |
| 1 | токен не найден или не принят |
| 2 | нужна авторизация: сессии нет или она истекла |
| 3 | окружение не готово: нет Playwright или браузера |
| 4 | недоступна сеть |

## Про токен

Измерено, а не предположено:

* **40 символов, только `0-9` и `a-f`.** Непрозрачная строка, **это не JWT**:
  точек нет, base64 нет, разобрать на части нельзя, срок годности внутри не
  написан.
* Появляется в адресе веб-сокета, который открывает веб-версия 2ГИС:

  ```
  wss://zond.api.2gis.ru/api/1.1/user/ws?appVersion=6.31.0&channels=markers,sharing,routes&token=<40 hex>
  ```

* **Сколько живёт — неизвестно.** Токен, полученный 2026-07-26, работал
  2026-08-16, то есть живёт не меньше трёх недель. Верхняя граница не
  установлена, эндпоинт обновления не найден. Чтобы закрыть вопрос
  наблюдением, есть `tools/token_watch.py`:

  ```bash
  2gis-token get --out data/token.txt
  python tools/token_watch.py --once      # в cron или Планировщик задач
  python tools/token_watch.py --report    # что накопилось
  ```

Раз токен живёт долго, программа нужна ради удобства, а не потому, что без неё
всё сыплется. Это осознанно: так она остаётся маленькой.

## Как это работает

Токен снимается **перехватом сетевой активности страницы**, а не выковыриванием
из внутреннего состояния приложения. Внутреннее устройство фронтенда меняется
при каждой переделке, а адрес сокета с параметром `token` — это протокол 2ГИС,
он живёт дольше.

Три сети, от надёжной к запасной: событие `websocket` в Playwright, его же
событие `request` (адреса и заголовки) и — на всякий случай — подмена
`WebSocket` и `fetch` скриптом на самой странице.

Кандидаты сравниваются по источнику. Сорок шестнадцатеричных знаков — это ещё
и любой sha1, а на странице карты их полно: отпечатки картинок, версии сборки,
идентификаторы тайлов. Поэтому токен из адреса сокета побеждает найденный
просто в тексте страницы, даже если тот пришёл раньше.

## Где лежит сессия

`storage_state.json` — это куки браузера, то есть фактически доступ к аккаунту.
Файл лежит не в рабочем каталоге, чтобы его нельзя было случайно закоммитить:

| Система | Путь |
|---|---|
| Windows | `%APPDATA%\2gis-token-extractor\storage_state.json` |
| macOS | `~/Library/Application Support/2gis-token-extractor/storage_state.json` |
| Linux | `~/.config/2gis-token-extractor/storage_state.json` |

Переопределяется ключом `--state ПУТЬ` или переменной окружения
`TWOGIS_TOKEN_STATE`. На unix-системах файлу выставляются права `600`.

Удалить файл — значит войти заново, больше ничего не сломается.

## Когда сессия истекла

`get` падает с внятным сообщением:

```
2gis-token: токен не появился за 60 с.
Чаще всего это значит, что сессия истекла — войди заново:
  2gis-token login
```

Код возврата 2. Выполняешь `2gis-token login` и работаешь дальше.

## Разработка

```bash
pip install -e ".[dev]"
python -m pytest -q
```

Тестам не нужен ни браузер, ни сеть, и проходят они за доли секунды. Это не
везение, а условие устройства: логика — опознание токена, разбор адреса
сокета, разбор ответа профиля, выбор путей, коды возврата — живёт в модулях
без тяжёлых зависимостей, а Playwright остаётся тонкой обвязкой вокруг них.

Тесты проверены мутациями: логика намеренно ломается, и тест обязан покраснеть.
Все четырнадцать испробованных поломок были пойманы.
