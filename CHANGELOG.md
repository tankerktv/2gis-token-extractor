# Изменения

Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

Раздел версии отсюда попадает в описание GitHub Release автоматически, поэтому
пишем человеческим языком: что изменилось для того, кто пользуется программой,
а не что поправлено в коде.

## [Не выпущено]

### Исправлено

**Двойной клик по `.exe` больше не выглядит как «ничего не запустилось».**
Программа консольная, и без команды делать ей нечего. Раньше она печатала две
строки ошибки и выходила, а Windows закрывала окно раньше, чем их успеваешь
прочесть, — со стороны это выглядело так, будто программа не запускается
вовсе. Теперь без команды показывается полная справка, а при запуске кликом —
ещё и подсказка, как запускать правильно, и окно ждёт Enter.

В README добавлено, что сборку стоит переименовать в `2gis-token` и запускать
из терминала.

## [0.1.1] — 2026-08-26

### Исправлено

**`get` больше не сдаётся с первой попытки.** Токен приезжает вместе с
загрузкой приложения 2ГИС, а оно иногда не доезжает — то ответ подвис, то
скрипт не выполнился. Теперь программа перезагружает страницу и ждёт снова;
перезагрузка стоит секунду и часто спасает заход, который раньше кончался бы
советом войти заново.

Срок при этом **делится между попытками, а не удваивается**: `--timeout`
остаётся полным бюджетом. Иначе ключ означал бы одно при удаче и вдвое больше
при неудаче, а на него полагаются расписания.

Если отпущено мало времени — меньше тридцати секунд, — попытка по-прежнему
одна: две по пятнадцать секунд хуже одной тридцатисекундной, не успеет ни та,
ни другая.

## [0.1.0] — 2026-08-26

Первый выпуск.

### Что она делает

**Выдаёт токен доступа к 2ГИС.** Один раз входишь в аккаунт в открывшемся окне
браузера — дальше программа печатает свежий токен по требованию:

```bash
2gis-token login          # один раз
export ZOND_TOKEN="$(2gis-token get)"
```

**Токен печатается в stdout и больше никуда.** Ни в файл, ни в лог он не
попадает, пока об этом не попросили ключом `--out`. В сообщениях вместо токена
показывается его отпечаток — по нему видно, тот же это токен или новый, а сам
токен из логов не утечёт.

**Телефон и код из SMS программа не видит.** Их вводит человек в окне
настоящего браузера, напрямую в 2ГИС. На диске остаются только куки браузера,
и лежат они в пользовательском каталоге настроек, а не рядом с проектом.

**`2gis-token check` отвечает, жив ли токен**, и различает три разных случая:
токен протух и нужно войти заново, 2ГИС отвечает ошибкой на своей стороне,
сети нет вовсе. Это разные беды, и лечатся они по-разному.

**Несколько аккаунтов держатся порознь.** Личный и рабочий — это две разные
сессии, и путать их не нужно:

```bash
2gis-token login --profile работа
2gis-token get --profile работа
```

Профили лежат в каталоге настроек, запоминать нужно только имя.
`2gis-token profiles` покажет те, в которые уже входили.

**Сессию трудно потерять.** Куки сохраняются после каждого захода, даже
неудачного: 2ГИС обновляет их при визите, и заход, не сохранивший обновлённые,
оставлял бы на диске уже негодные — а это лишний вход по SMS на ровном месте.
Файл при этом не правится на месте, а заменяется целиком, так что сбой
посередине не оставит половину сессии. Два одновременных захода к одной сессии
не допускаются: второй получает внятный отказ вместо испорченного входа.

**Понятно, что делать, когда токена нет.** Программа различает «страница не
загрузилась» и «загрузилась, но токена не дала»: первое лечится не входом
заново, а проверкой доступа к 2gis.ru, и путать их — значит гонять человека
за SMS впустую.

**Справка `--help` на английском** — с примерами и кодами возврата.

### Как устроено

**Работает на Windows, macOS и Linux.** Ставится одной командой
`pipx install git+https://github.com/tankerktv/2gis-token-extractor.git`;
для тех, у кого нет Python, к релизу приложены однофайловые сборки под все
три системы.

**Программа говорит по-английски** — справка, подсказки и сообщения об
ошибках. Русскими остались CHANGELOG и внутренние записи: они для того, кто
правит код, а не для того, кто программой пользуется.

**Коды возврата пригодны для скриптов:** `0` — успех, `1` — токен не найден или
не принят, `2` — нужна авторизация, `3` — не хватает браузера или Playwright,
`4` — недоступна сеть.
